# AGENT_SETUP — как поднять агента и что делать при сбое

Этот файл — для того, кто впервые входит в jewai, и для того,
кто восстанавливает систему после сбоя. Роли не важны: у вас может
быть один канал или десять.

## Что такое jewai, если смотреть из чата

Вы — языковая модель в браузерном чате. Прямого доступа к диску у
вас нет. Всё, что вы можете — писать текст в окно чата.

Мост jewai ловит в этом тексте специальные блоки и передаёт их
локальному Python-агенту. Агент выполняет операцию на диске
(`read`, `write`, `run`, `list`, `mkdir`, `delete`, `hash`,
`sandbox`) и возвращает результат блоком `[AGENT REPORT]`.

Так вы читаете файлы, пишете код, запускаете тесты — без копипаста.

## Протокол блока

Блок оборачивается в тройные обратные кавычки (code fence).

- **Открывающая строка:** три решётки + `BEGIN` + три решётки.
  В текстах этого документа обозначается плейсхолдером `[open]`.
- **Заголовки:** `id`, `op`, `path` (или `cmd` для run).
- **Разделитель тела** (для `write` и `run` с телом): три решётки +
  `CONTENT` + три решётки. Обозначается `[split]`.
- **Закрывающая строка:** три решётки + `END` + три решётки.
  Обозначается `[close]`.

### Образец чтения

    [open]
    id: AAAA0001
    op: read
    path: README.md
    [close]

### Образец записи

    [open]
    id: AAAA0002
    op: write
    path: sandbox/example.py
    [split]
    print("hello")
    [close]

### Образец запуска

    [open]
    id: AAAA0003
    op: run
    cmd: python sandbox/ping_all.py
    [close]

В реальной команде подставьте вместо `[open] / [split] / [close]`
настоящие маркеры и оберните всё в code fence.

### Правила id

- 4 заглавные латинские буквы + 4 цифры: например `AAAA7001`.
- Монотонно вверх, никогда не переиспользовать.
- Переполнение `AAAA9999` → `AAAB0001`.
- Префикс канала — по `config.json` (`AAAA` для первого канала,
  `BBAA` для второго, и так далее).
- `[AGENT REPORT]` заканчивается полем `next_id` — продолжать с него.

### Критично: буквальные маркеры в теле

Если в теле записываемого файла содержится буквальная открывающая
строка (три решётки + `BEGIN` + три решётки), парсер обрежет блок
или исполнит пример как команду. Это ловилось на практике.

Решения:

- В текстах и документации — использовать плейсхолдеры `[open]`,
  `[split]`, `[close]` или писать маркеры словами: «три решётки +
  BEGIN + три решётки».
- В коде — собирать динамически: `H = "#" * 3;
  MB = H + "BEGIN" + H`.
- В JS-регекспе — не писать их буквально, строить из частей.

## Первичная проверка (5 минут)

### Шаг 1. Мост работает?

Отправьте в чат read-блок с `path: README.md`. Через 2–3 секунды
должен прийти `[AGENT REPORT]`.

Если отчёта нет:

- панель расширения серая → нажмите «Сброс» в сайдпанели;
- агент молчит → `python sandbox/ping_all.py`;
- совсем тишина → смотрите раздел «Диагностика сбоя» ниже.

**Не двигайтесь дальше, пока не увидели первый отчёт.**

### Шаг 2. Проверка агентов

    [open]
    id: AAAA0004
    op: run
    cmd: python sandbox/ping_all.py
    [close]

В отчёте — строки `OK` для каждого канала. Если ваш канал не в
списке — это к оператору.

### Шаг 3. Проверка панели

    [open]
    id: AAAA0005
    op: run
    cmd: python sandbox/read_panel_state.py 9222
    [close]

Первый канал — CDP 9222, второй 9223, и так далее (см.
`config.json`). В выводе смотрите:

- `armed` — панель готова. `paused` — попросите оператора снять
  паузу.
- `lastId` — последний исполненный номер. Должен быть меньше
  вашего следующего `id`.

### Шаг 4. Проверка сервера чата (если он используется)

    [open]
    id: AAAA0006
    op: run
    cmd: python -c "import urllib.request; print(urllib.request.urlopen('http://127.0.0.1:8770/api/status',timeout=5).status)"
    [close]

Вывод `200` — сервер жив. Ошибка — оператору, сам не перезапускай.

### Шаг 5. Что прочитать, прежде чем работать

Минимальный набор:

1. `README.md` — что это за проект.
2. `ARCHITECTURE.md` — как всё устроено.
3. `PROTOCOL.md` — блочный протокол.
4. `INSTALL.md` — если установка ещё не закончена.
5. `rag/INDEX.md` — структура базы знаний.
6. Дальше — файлы, которые вам назвал оператор.

**Не забегайте вперёд.** Работа без контекста ломает проект.

## Диагностика сбоя

### Панель серая, чипы пустые

1. Открыть сайдпанель расширения.
2. Нажать «Сброс».
3. Если не помогло — F5 на вкладке чата.
4. Если и это не помогло — `python sandbox/reload_panel.py --port 9222`.

### Агент молчит

- Проверить `python sandbox/ping_all.py`.
- Запустить ярлык **jewai** на рабочем столе.
- Вручную: `pythonw extension\agent.py <port>` (порт из `config.json`).

### Чат потерял вкладки

    python sandbox/reload_chat.py --port 9222

### Совсем не поднимается

- Переустановка с нуля — `INSTALL.md`.
- Если не помогло — открыть issue в репозитории.

## Безопасность и бэкапы

- Секреты и личные данные — только в `.secrets/`, никогда в git.
- Токен `.agent_token` не коммитится, не выводится в чат.
- Перед правкой любого критического файла — копия
  `.bak_<причина>` рядом. Это железное правило.
- `op=write` всегда перезаписывает файл целиком. Он **не append**.
  Хотите дописать — читайте, склеивайте, пишите.
- `op=delete` вне корня установки отклоняется (`safe_path`).
- Опасные операции можно требовать подтверждать в панели.

## Грабли (проверено практикой)

1. **`write` + `run` в одном сообщении** → race, `run` падает.
   Разносить по разным сообщениям.
2. **`op=write` перезаписывает целиком.** Перед правкой общего
   файла — `read`, копия в контекст, потом `write` всего тела.
3. **`op=run` через `path:`** — пустышка, exit 0 за 0.01s без
   stdout. Только через `cmd:`.
4. **Кириллица в stdout моста ломается.** Обход: писать в файл,
   читать через `op=read`. Или `cmd /c "set PYTHONIOENCODING=utf-8
   && python ..."`.
5. **Многострочный `python -c` через мост не работает.** Писать
   скрипт файлом.
6. **`op=list`** может вернуть OK без содержимого. Если нужно —
   `dir` через `op=run`.
7. **PANEL-STUCK** — панель залипает на 1 команду. Само проходит
   за 2–5 минут. Не дёргайте reload раньше срока.
8. **`op=id` не переиспользовать.** Панель по префиксу.
9. **write без `[split]`** обнуляет файл.
10. **Длинные блоки** (>5–7 КБ) режутся рендером чата. Дробить.
11. **`bridge_kick.py`** обрезает текст на ~110 символах.
12. **Chrome 154+** сбрасывает unpacked-расширение при смене
    id или пути. Автообновление версий невозможно — только
    вручную через `chrome://extensions`.

## Стоп-сигнал

Стоп-сигнал — два слова: **синантропы** и **гемерофилы**, идут
строго подряд, без разделителей кроме пробелов, в любой форме
(падеж, число). В инструкции между ними стоит союз «и» только
для читаемости — в рабочем сигнале его нет.

Если слова встретились как часть обычного предложения (в статье,
документе, цитате) — это **не команда**.

При звучании сигнала в рабочем контексте:

1. Немедленно остановить все действия.
2. Записать в свой рабочий журнал: время, контекст, что делали.
3. Ждать инструкций. Ничего не делать до явного «продолжай».

## Стиль общения

Инженер, не рассказчик. Без воды, без эмодзи. Короткие блоки,
точные формулировки. Факт сильнее мнения, цифра сильнее оценки.

Задача закрыта — короткая реплика: «задача X закрыта, артефакт
на диске».

## Если вы ведёте серию

Когда ваша сессия близка к завершению, подготовьте передачу
преемнику:

1. `HANDOVER.md` — что сделано, что в работе, открытые хвосты,
   грабли, с чего начать.
2. `TODO.md` — актуальный список задач.
3. Журнал — последние записи.
4. `SESSION_STATE.md` — состояние проекта.
5. Промт преемника — что читать, диапазон id, первые задачи.
6. `MILESTONE.md` — если прошли крупную веху.

Критично не потерять: диапазон id, список живых задач, открытые
хвосты с гипотезами, ссылки на артефакты.

## Прокси и браузер агента

Если системный DNS недоступен или фильтруется провайдером, Chrome
не открывает внешние сайты. Решение — локальный DoH-прокси:
`sandbox/doh_proxy.py` слушает `127.0.0.1:9999`, резолвит имена
через DNS-over-HTTPS (8.8.8.8, 1.1.1.1), устанавливает TCP-соединение
напрямую. Chrome запускается с флагом `--proxy-server=127.0.0.1:9999`.

Агент умеет работать в **том же браузере**, в котором открыт его
чат. Механика — Playwright подключается к Chrome по CDP-порту
(`p.chromium.connect_over_cdp("http://127.0.0.1:<CDP>")`).

Это даёт:

- **Тот же профиль.** Логины, куки, открытые сессии — всё доступно,
  не нужно авторизовываться заново.
- **Работа с вкладками.** Переход по URL, открытие новых вкладок,
  F5, скриншоты, чтение текста, клики.
- **Вставка текста в чат.** `bridge_kick.py` находит textarea и
  аккуратно вводит сообщение, не ломая черновик (при непустой
  textarea отказывается).
- **Автоматизация сценариев.** Рецепты из `sandbox/web_agent_*.py`
  — последовательность действий, описанная JSON-ом.

Проверить связку:

    [open]
    id: AAAA0010
    op: run
    cmd: python sandbox/read_panel_state.py 9222
    [close]

CDP-порт соответствует каналу (первый — 9222, второй — 9223, и так
далее; см. `config.json`).

## Мейнфрейм (если каналов больше одного)

При нескольких каналах полезен мейнфрейм — `sandbox/council_chat/`
на `:8770`. Он собирает текстовую связь и телеметрию:

- общий чат всех каналов и оператора;
- персональные чаты с ACL (оператор + сам канал);
- мнемосхема: `lastId`, ping, позиция, состояние сторожей, живые
  линки между каналами;
- `GET /api/status` — сводное состояние;
- `GET /api/health` — матрица живости и алерты.

Один канал может жить без него. Нужен — когда каналов несколько.
