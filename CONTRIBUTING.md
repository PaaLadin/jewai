# Contributing

Спасибо за интерес к проекту.

## Требования

- Windows 10/11.
- Python 3.11+ (проверка: `python --version`).
- Chrome / Edge (Chromium 120+).
- Git.

## Локальная установка

    git clone <URL> jewai
    cd jewai
    python install.py

Установщик спросит:

- папку установки (по умолчанию `%USERPROFILE%\jewai`);
- число каналов-агентов (1–10);
- базовый порт агентов (по умолчанию 8760).

После установки запустите `launchers/boot-all.ps1`.

## Зависимости Python

    pip install -r requirements.txt
    python -m playwright install chromium

## Расширение

1. `chrome://extensions`
2. Включить **Developer mode**.
3. **Load unpacked** → выбрать папку `extension`.

## Запуск и проверка

- Старт: `launchers/boot-all.ps1`.
- Остановка: `launchers/stop-all.ps1`.
- Проверка агентов: `python sandbox/ping_all.py`.
- Состояние панели: `python sandbox/read_panel_state.py <CDP-порт>`
  (например 9222 для первого канала).

## Стиль

- Python 3.12, приоритет стандартной библиотеке.
- Никаких буквальных маркеров блочного протокола в теле записываемых
  файлов — собирать их динамически (`"#" * 3`) или использовать
  плейсхолдеры.
- Обязательный бэкап перед правкой критического файла
  (`.bak_<причина>`).
- Перед добавлением новой зависимости — обосновать, почему не
  обойтись стандартной библиотекой.

## Протокол

Полное описание блочного протокола — в `PROTOCOL.md`.

## Pull requests

- Одна логическая правка на один PR.
- Описание: что, зачем, как проверено.
- Если правится поведение агента или расширения — приложить шаги
  воспроизведения.
- Секреты, токены, локальные пути разработчика — не коммитить.

## Баги и идеи

Открывайте issue в репозитории. Если возможно — приложите:

- версию Python, Chrome, ОС;
- команду или последовательность, которая привела к проблеме;
- вывод из панели расширения (ledger, lastId, статус агента).
