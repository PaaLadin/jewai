# INSTALL — установка jewai

## Что это

JewAI — мост между чатом LLM
и локальной файловой системой Windows. Позволяет LLM писать код,
запускать его, читать вывод, управлять браузером — без ручного
копипаста.

**Ключевая особенность:** разворачивается в **любую** папку.
Никаких хардкодов `%USERPROFILE%\jewai`. Всё внутри одной папки
установки (вариант А).

## Требования

- Windows 10/11.
- Python 3.11+ (проверка: `python --version`).
- Chrome / Edge (Chromium 120+).
- Свободные порты: 8760+ (агенты), 9220+ (CDP), 8770+ (сервер чата).
- Аккаунт LLM — для чата, из которого будете работать.

## Быстрый старт

### 1. Скопировать jewai

    cd <любая папка>
    git clone <URL> jewai
    cd jewai

или просто развернуть из архива.

### 2. Установить зависимости

    pip install -r requirements.txt
    python -m playwright install chromium

### 3. Запустить установщик

    python install.py

Установщик спросит:

- **Папка установки** — по умолчанию `%USERPROFILE%\jewai`.
  Можно указать любую, например `C:\Projects\jewai`.
- **Сколько каналов-агентов (1–10)** — для старта достаточно 1.
- **Базовый порт агентов** — по умолчанию 8760.
- **Порт DoH-прокси** — по умолчанию 9999.

Установщик создаст:

- структуру папок: `sandbox`, `extension`, `launchers`,
  `emergency`, `rag`, `logs`, `runtime`, `.secrets`,
  `templates/agent_logs`;
- профили Chrome (`chrome-A-data`, `chrome-B-data`, ...);
- `config.json` с раскладкой портов, каналов и префиксов;
- `launchers/` — все `.ps1` под N каналов, включая `boot-all.ps1`
  и `create-shortcut.ps1`;
- `.agent_token` со случайной строкой (если ещё нет).

**Идемпотентен:** повторный запуск не ломает существующую
установку.

### 4. Создать ярлык на рабочем столе

    cd launchers
    powershell -ExecutionPolicy Bypass -File create-shortcut.ps1

На рабочем столе появится ярлык **jewai** — запускает `boot-all.ps1`.

### 5. Первый запуск

    cd launchers
    powershell -ExecutionPolicy Bypass -File boot-all.ps1

Или двойной клик по ярлыку **jewai**.

`boot-all.ps1` поднимает по `config.json`:

1. `doh_proxy` на 9999.
2. Все агенты (N каналов) в фоновых окнах (`pythonw`).
3. Все Chrome с профилями, CDP, прокси, расширением.
4. Сервер чата на порту `chat_port`.
5. Health-проверка всех портов, лог в `runtime/boot.log`.

**Никаких окон консоли на экране** — все процессы через `pythonw`.

### 6. Установить расширение в каждом Chrome

Для каждого открытого Chrome:

1. `chrome://extensions`
2. Включить **Developer mode**.
3. **Load unpacked** → выбрать папку `extension` из установки.
4. Расширение появится как **JewAI**.

### 7. Настроить сайдпанель

В каждом Chrome:

1. Открыть `chat.deepseek.com`.
2. Кликнуть иконку расширения — откроется сайд-панель.
3. Заполнить:
   - **Token** — тот же, что в `.agent_token`;
   - **Agent URL** — `http://127.0.0.1:<agent_port>` для своего
     канала (см. `config.json`);
   - **lastId** — оставить пустым.
4. Нажать **Set**, затем **Self-test**.

Чипы **agent** и **content** зелёные, кнопка **armed**.

### 8. Проверка связки

В чате LLM написать блок с `op: read` и `path: README.md`.
Через 1–3 секунды вернётся `[AGENT REPORT]`.

## Проверка и диагностика

### Все агенты живы?

    python sandbox\ping_all.py

Все строки `OK`.

### Здоровье системы

    python sandbox\health_matrix.py

### Панель серая, чипы пустые

Двойной клик по ярлыку **jewai** или:

    python sandbox\reload_panel.py --port <cdp>

### Не поднимается агент

    pythonw extension\agent.py <port>

### Chrome не ходит в интернет

Проверить DoH-прокси:

    python sandbox\doh_proxy.py --test

## Что делается вручную (Chrome)

Архитектурное ограничение Google:

- **Load unpacked** расширения — только клик.
- Логин в Google/LLM — вручную.
- Подтверждение личности Chrome при первом запуске на новой машине.

Всё остальное автоматизируется.

## Параметры config.json

Основные поля:

- `root` — абсолютный путь установки.
- `n_agents` — число каналов (1–10).
- `letters` — буквы каналов: `["A", "B", ...]`.
- `agent_port_base` — базовый порт агентов (по умолчанию 8760).
- `cdp_port_base` — базовый CDP-порт (по умолчанию 9220).
- `chat_port` — порт сервера чата (по умолчанию 8770).
- `proxy_port` — порт DoH-прокси (по умолчанию 9999).
- `extension` — имя папки расширения (по умолчанию `extension`).
- `bind` — интерфейс сервера чата. `127.0.0.1` (только с этой
  машины) или `0.0.0.0` (доступно в локальной сети).
- `channels` — карта каналов: `{ "A": {"agent": 8760, "cdp":
  9220, "prefix": "AAAA"}, ... }`.

### Пример: сделать чат доступным в локальной сети

Добавить в `config.json`:

    "bind": "0.0.0.0"

Перезапустить сервер чата. Станет доступно по
`http://<имя-машины>:8770/` или `http://<IP>:8770/`.
