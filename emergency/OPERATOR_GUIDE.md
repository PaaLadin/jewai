# OPERATOR_GUIDE — что делает оператор при сбое

**Кому:** оператор.
**Когда:** агент молчит, панель мертва, чат не отвечает.

---

## Диагностика (5 минут)

### Шаг 1. Агенты живы?

    python sandbox/ping_all.py

Ожидание: строки `OK` для каждого канала.

- Все OK → к шагу 2.
- Кто-то молчит → перезапустить ярлык **jewai** на
  рабочем столе. Он поднимет агентов и Chrome.

### Шаг 2. Панели живы?

Открыть сайдпанель расширения в каждом Chrome. Смотреть чипы:

- `agent` — версия и порт.
- `content` — версия.
- `lastId` — число или пусто.
- Статус — `armed` / `paused`.

Если панель серая или `content no-answer`:

- нажать **Сброс** в сайдпанели;
- либо в PowerShell: `python sandbox/reload_panel.py --port <CDP>`.

### Шаг 3. Чат отвечает?

Открыть чат. Написать простую команду — блок с `op: read`,
`path: README.md`. Ждать 2–3 секунды.

- Ответ пришёл → работаем дальше.
- Не пришёл → к шагу 4.

### Шаг 4. Мост завис?

- Проверить `python sandbox/read_panel_state.py <CDP>`.
- Если `lastId` стоит на месте больше 5 минут — панель залипла
  (**PANEL-STUCK**). Обычно проходит за 2–5 минут. Не дёргай
  reload раньше срока.
- Если `content` серый — нажать F5 на вкладке чата.

---

## Восстановление

### Агент упал (модель молчит, но панель жива)

1. Проверить `ping_all.py`.
2. Если агент отвечает, а модель нет — это проблема чата,
   а не моста:
   - нажать F5 на вкладке;
   - подождать 1 минуту.
3. Если чат переполнен («Достигнут предел длины») — открыть
   новый чат, передать агенту `0_ACTIVATION.md` + промт, см.
   `RECOVERY_PROTOCOL.md`.

### Панель мертва

1. Кнопка **Сброс** в сайдпанели.
2. `python sandbox/reload_panel.py --port <CDP>`.
3. `python sandbox/reload_extension.py --port <CDP>` (крайняя мера).

### Всё сломалось

Ярлык **jewai** на рабочем столе — поднимает агентов
и Chrome. Если и это не помогает — переустановка, см. `INSTALL.md`
в корне проекта.

---

## Чего не делать

- Не нажимать F5 на вкладках без необходимости — теряется позиция.
- Не перезагружать расширение через `chrome://extensions` без
  страховки — убивает `content.js` на всех вкладках.
- Не использовать `start /B` в PowerShell.
- Не закрывать вкладки чатов без причины.

## Голосовые оповещения

    python sandbox/voice.py alarm "текст"   — срочный вызов
    python sandbox/voice.py done "текст"    — завершение задачи
    python sandbox/voice.py stuck "текст"   — «застрял»
    python sandbox/voice.py say "текст"     — свободный текст
