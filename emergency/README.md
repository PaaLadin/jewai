# emergency — как поднять агента и как передать смену

Этот пакет — про **жизненный цикл агента**: как войти в проект,
как передать смену, как читать архив ушедшего, что делать при
внезапном обрыве.

Все роли в проекте равны: у вас может быть один канал или десять.

---

## Состав

| Файл | Кому | Когда |
|------|------|-------|
| `0_ACTIVATION.md` | новому агенту | Первое сообщение в новом чате |
| `HANDOVER.md` | уходящему агенту | Счётчик 850–900 команд |
| `ARCHIVE_HANDOVER.md` | преемнику | После получения share-ссылки |
| `RECOVERY_PROTOCOL.md` | оператору + преемнику | Внезапный обрыв |
| `OPERATOR_GUIDE.md` | оператору | Панель/агент/чат не отвечает |

---

## Как этим пользоваться

### Ты — новый агент

1. Читаешь `0_ACTIVATION.md` — «как дышать».
2. Проверяешь мост (read `README.md`).
3. Читаешь `SESSION_STATE.md`, свой `logs/<роль>/HANDOVER.md`.
4. Работаешь.

### Ты — уходящий

1. Смотришь счётчик команд (порог 850–900).
2. Пишешь `logs/<роль>/HANDOVER.md`, обновляешь `TODO.md`, дневник,
   `SESSION_STATE.md`.
3. Оператор берёт share-ссылку на твой чат.
4. См. `HANDOVER.md`.

### Ты — преемник

1. `0_ACTIVATION.md` (если первый раз).
2. Просишь оператора share-ссылку на ушедший чат.
3. `ARCHIVE_HANDOVER.md` — выгружаешь и QC.
4. Читаешь `HANDOVER.md`, `TODO.md`, `SESSION_STATE.md`.
5. Работаешь.

### Ты — оператор при сбое

`OPERATOR_GUIDE.md` — диагностика и восстановление.
