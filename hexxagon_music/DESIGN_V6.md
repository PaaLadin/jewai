# Дизайн v6 — звёздная система, лор, прогрессия

## 1. Лор

Галактика **Music Star** — звезда и 10 обитаемых планет.
На каждой планете — свой музыкальный стиль (см. таблицу ниже).
Планеты захватили **Silence Monster** из соседней галактики —
музыка стихла, инструменты разбросаны по полю.

Игрок — пилот корабля-освободителя. Задача: освободить все планеты,
вернуть музыку. Чем ближе планета к звезде — тем горячее/быстрее
биты и сильнее ИИ соперника.

## 4. Рубка корабля (выбор планеты)

- Вид из кабины: звёздная система на фоне, планеты кликабельны.
- Слева/снизу — список планет, при наведении подсвечивается на экране.
- Панель настроек: скафандр роботов (SoundPack: 8-бит/аналог/
  акустика/цифра), сложность (авто по планете).
- Освобождённые планеты помечены (✓), кнопка «Лететь».

## 5. Скафандр → SoundPack

Тип скафандра = звуковая система роботов:
- 8-бит → SoundPacks.chip
- аналог → SoundPacks.analog
- акустика → SoundPacks.acoustic
- цифра → SoundPacks.digital

## 6. Счёт (рекорды)

**Планеты × Инструменты.**
- Освободил планету, захватил N из 7 инструментов → N очков.
- Захватил центральное поле → ×2 (2×N).
- Итого = Σ по планетам.

Примеры:
- 3 планеты, по 3/3/4 инструмента без центра → 3+3+4 = 10.
- Планета с центром и 7 инструментов → 14.
- Планета без центра, 6 инструментов → 6.

## 7. Прогрессия (сохранение)

localStorage `hexxagon_v6_progress`:
- `planets`: { blues: {won:true, tools:5, center:true}, ... }
- `totalScore`: сумма.
- `unlocked`: список освобождённых планет.

## 8. Трекер

- Слушать все 10 стилей + 30 авторских треков.
- Разблокировка по прогрессу: стиль доступен, если его планета
  освобождена (в отладке — всё открыто).
- ИИ-сиды: рандом + сохранение — открывается после освобождения
  ВСЕХ планет с 2×7 (центр + все инструменты).
- Флаг DEBUG_UNLOCK_ALL = true (в релизе false).

## 9. Баг v5: смена стиля после победы

Причина: секвенсор не сбрасывает currentStep/nextNoteTime при
смене стиля. Фикс: в `setStyle` сбрасывать позицию и
пересобирать timeline.
