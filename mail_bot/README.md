# mail_bot — приём писем -> кик агентам

**Статус:** MVP работает (10.10.2026).
**Версия:** 0.1.0.

## Что это

Опрашивает INBOX личного Яндекс-ящика, парсит Subject на маркер
адресата, роутит задачу киками агентам A/B/C/D или broadcast
в общий чат 8770.

Позволяет ставить задачи агентам с телефона — просто отправив
письмо.

## Формат письма

**Subject:** начинается с маркера адресата:

- `[A] ...` — задача Аркадию (кик в порт 9222).
- `[B] ...` — Борису (9223).
- `[C] ...` — Семёну (9224).
- `[D] ...` — Димону (9225).
- `[ALL] ...` — broadcast в общий чат 8770.

**Body:** текст задачи. Попадает агенту в кик после заголовка
с маркером `[OP>X]` — знак, что пришло почтой.

## Быстрый старт

    python projects/mail_bot/mail_bot.py --once
    python projects/mail_bot/mail_bot.py --loop --interval 1800

Для фона — через pythonw (без окна консоли).

## Конфиг

Читает `.smtp_token` из корня проекта (тот же, что send_email.py):
host, port, sender, recipient, password. IMAP-хост получается
заменой smtp. -> imap. (imap.yandex.ru).

## Whitelist

Принимаются только письма от адресов из `WHITELIST` в mail_bot.py.
Иначе — SKIP, письмо не роутится.

## Состояние

`logs/last_uid.json` — последний обработанный UID. Письма с
меньшим UID игнорируются.

## Логи

`logs/YYYY-MM.md` — ежедневная сводка.

## Безопасность

- Реальные креды — только в .smtp_token, не в репо.
- Whitelist обязателен, иначе любой спамер получает управление.
- При старте берётся последний UID, старые письма не обрабатываются.
