# sandbox — инструменты

Скрипты управления мостом, восстановления, браузерной
автоматизации. Запускаются через `op=run` (см. `../PROTOCOL.md`)
или напрямую из PowerShell.

---

## Проверка и мониторинг

| Файл | Назначение |
|------|-----------|
| `ping_all.py` | Проверка живости всех агентов |
| `health_matrix.py` | Матрица живости каналов |
| `read_panel_state.py` | Снимок состояния панели по CDP-порту |
| `read_panel_lastid.py` | Только lastId и время сессии |
| `read_heartbeat.py` | Жива ли панель (панель отвечает?) |
| `validate_js.py` | Проверка JS-файлов расширения |

## Чат и кики

| Файл | Назначение |
|------|-----------|
| `bridge_kick.py` | Отправка текста в чат через CDP |
| `reload_chat.py` | F5 вкладки чата |
| `reload_panel.py` | Перезагрузка сайдпанели |
| `reload_extension.py` | Перезагрузка расширения |
| `reload_all_chats.py` | F5 всех чатов сразу |
| `reset_panel_ledger.py` | Сброс ledger панели |
| `recover_chat.py` | Полное восстановление пары чат+панель |

## Сервисы и сторожа

| Файл | Назначение |
|------|-----------|
| `watchdog.py` | Health-монитор агента (ALERT.json) |
| `watchdog_v3.py` | Watchdog третьей версии |
| `watchdog_indep.py` | Независимый watchdog |
| `recovery_loop.py` | Цикл автоподъёма |
| `svc.py` | Персональные сервисы (per-channel) |
| `guard.py` | Таймерная страховка критических операций |
| `tool_light.py` | Лёгкая чистка зомби-сервисов |

## Голос, почта, уведомления

| Файл | Назначение |
|------|-----------|
| `voice.py` | Голосовое оповещение (SAPI) |
| `notify_me.py` | Триггер голосового уведомления |
| `call_user.py` | Срочный вызов оператора |
| `done_notify.py` | Уведомление о завершении задачи |
| `send_email.py` | Отправка email (если настроен `.smtp_token`) |

## Обустройство

| Файл | Назначение |
|------|-----------|
| `mk_agent_folder.py` | Создание папки агента из шаблона |
| `mk_shortcuts.py` | Ярлыки на рабочем столе |
| `no_window.py` | Патч: скрытие окна cmd при запуске процессов |

## Восстановление

| Файл | Назначение |
|------|-----------|
| `restart_8770.py` | Жёсткий перезапуск мейнфрейма |
| `restart_via_b.py` | Перезапуск агента A через мост B |

## Сеть и DoH

| Файл | Назначение |
|------|-----------|
| `doh.py` | DNS-over-HTTPS резолвер |
| `doh_proxy.py` | Локальный CONNECT-прокси на 9999 |
| `start_proxy.py` | Проверка и запуск прокси |
| `search.py` | DuckDuckGo-поиск (текст и картинки) |
| `wiki.py` | Wikipedia REST API |

## Браузерная автоматизация

| Файл | Назначение |
|------|-----------|
| `pwlib.py` | Обёртка над Playwright |
| `browser_agent.py` | Рецепт-ориентированное управление браузером |
| `browser_loop.py` | Цикл задач из `browser_tasks.json` |
| `web_agent_v2.py` | CDP-агент, простая версия |
| `web_agent_v3.py` | CDP-агент, действия из JSON-рецепта |
| `web_agent_v4.py` | CDP-агент с vision и условными шагами |

## Тесты и очереди

| Файл | Назначение |
|------|-----------|
| `runner_v3.py` | Параллельный раннер тестов |

| `agent_loop.py` | Декларативная очередь задач |

---

## Правило

Каждый скрипт делает **одно** дело. Не плодить копии. При
необходимости расширять существующий.
