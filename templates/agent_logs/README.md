# templates/agent_logs — шаблоны папки агента

Что копируется в `logs/<роль>/` при создании канала.

| Файл | Назначение |
|------|-----------|
| `HANDOVER.md` | Передача следующему поколению |
| `TODO.md` | Задачи (открыто / закрыто) |
| `NOTES.md` | Грабли и наблюдения |
| `README.md` | Описание роли |

Копируется установщиком (`install.py`) при создании папки агента.
