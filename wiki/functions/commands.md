# Команды

Агент в чате оборачивает каждую операцию в блок. Мост читает поле `op` и
выполняет соответствующее действие.

## Операции

| op | Что делает | Обязательные поля |
|---|---|---|
| `read` | Прочитать файл | `path` |
| `list` | Показать содержимое папки | `path` |
| `write` | Записать файл (целиком) | `path` + тело |
| `mkdir` | Создать папку | `path` |
| `delete` | Удалить файл или папку | `path` |
| `hash` | Посчитать sha256 | `path` |
| `run` | Выполнить команду ОС | `cmd`, `cwd`, `timeout` |

## Формат блока

- Открывающая строка: три решётки + `BEGIN` + три решётки.
- Каждое поле на своей строке: `id: ...`, `op: ...`, `path: ...`.
- Закрывающая строка: три решётки + `END` + три решётки.

## Правила id

- Формат: 4 буквы канала + 4 цифры (например AAAB1234).
- Только по возрастанию, никогда не переиспользовать.
- Мост сам возвращает `next_id` — с него продолжать.

## Ограничения

- `write` перезаписывает файл **целиком**, не дописывает.
- `write` больше ~1.5 КБ может потеряться — крупный файл писать скриптом.
- `run` не дольше 60 секунд — длинное уходит в фон.
