# Установка и запуск

JewAI v5 устанавливается инсталлятором, который сам настраивает конфиги,
скачивает браузер и создаёт ярлыки.

## Что делает установщик

1. Копирует файлы проекта в целевую папку.
2. Спрашивает имя и параметры каналов.
3. Создаёт конфиг (порты, каналы, имена).
4. Скачивает Chrome for Testing (отдельный браузер, не трогает твой основной).
5. Создаёт лаунчеры (ярлыки для запуска каналов).
6. Открывает окно первого запуска с инструкцией.

## Первый запуск

1. Запусти лаунчер (ярлык на рабочем столе или файл в папке проекта).
2. Откроются окна Chrome — по одному на канал.
3. В каждом окне — залогинься в чат (DeepSeek или другой, по настройке).
4. Откроется панель оператора — адрес в консоли запуска.
5. Проверь лампы: все зелёные — установка готова.

## После установки

- **Не логинь Chrome в Google.** Достаточно логина в сам чат.
- **Профили Chrome** — папка `Profiles/<буква канала>/`. Не удаляй — потеряешь логин.
- **Пароль почты** — если нужен SMTP, добавь в `.secret/` (см. [[functions/smtp]]).

## Остановка

- Лаунчер «stop-all» — мягко останавливает всё.
- Или через панель: кнопка «Стоп» на каждом канале.

## Если что-то пошло не так

- Открой лог установки (`install.log` в корне проекта).
- Проверь: установлен ли Python, есть ли права на папку.
- Ошибки Chrome — см. [[troubleshooting/chrome-crashed]].
