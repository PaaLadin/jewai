# Логин в чат

Каждый канал — отдельный Chrome со своим профилем. Логиниться нужно один раз,
сессия сохраняется в профиле.

## Порядок

1. Открой нужное окно Chrome (JewAI запускает при старте).
2. Адрес: `chat.deepseek.com` (A-D) / `chat.qwen.ai` (E) / `alice.yandex.ru` (F).
3. Войди в аккаунт.
4. Правый клик по вкладке → «Закрепить».

## Не логинь Chrome в Google

Достаточно логина в сам чат. Google добавит лишние сервисы и риск смешать
куки разных агентов.
