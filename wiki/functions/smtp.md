# SMTP — почта

JewAI умеет отправлять письма и принимать их — как уведомления оператору
и как канал для задач.

## Как устроено

- **Отправка**: агент или UI вызывает API панели → панель читает конфиг почты →
  отправляет через SMTP-сервер провайдера.
- **Приём**: по IMAP — JewAI проверяет ящик и может обработать письмо
  как новую задачу (mail-bot).
- **Конфиг**: отдельный файл в `.secret/`, **не в git**. Причина — там пароль.

## Провайдеры

| Провайдер | Порт | Тип шифрования | Пароль |
|---|---|---|---|
| Yandex | 465 | SSL | пароль приложения |
| Gmail | 587 | STARTTLS | App Password (нужен 2FA) |
| Mail.ru | 465 | SSL | пароль приложения |

Обычный пароль от почты не подходит — нужен «пароль приложения»,
который провайдер выдаёт отдельно.

## Что видит оператор

- Если почта настроена — уведомления о завершении задач приходят на email.
- Если нет — уведомления только в панели.

## Что видит агент

- Может отправить письмо как tool (если разрешено).
- Может проверить входящие (если настроен IMAP).
- **Пароль агент не видит** — только панель, только для отправки.

## Безопасность

- Файл с паролем — в `.secret/`, в `.gitignore`.
- Если пароль попал в git — сменить пароль и вычистить историю.
- Агенты не печатают пароль в чат.
