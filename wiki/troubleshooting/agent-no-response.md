# Агент не отвечает

Агент в чате не реагирует на команды, отчёты моста не приходят.

## Что проверить по порядку

1. **Окно Chrome живое?** Открой окно канала — вкладка с чатом на месте?
2. **Поле ввода пустое?** Если там висит черновик — агент его не отправит.
   Очисти вручную.
3. **Чат не переполнен?** Если видишь баннер «лимит» — пора перерождать.
4. **Панель зелёная?** Открой панель оператора, посмотри на карточку канала.

## Что делать

- **Chrome закрыт или упал** → см. [[troubleshooting/chrome-crashed]].
- **Чат переполнен** → см. [[functions/rebirth]].
- **Поле ввода с черновиком** → очистить.
- **Ничего не помогло** → перезапусти канал через панель (кнопка Перезапуск).

## Что НЕ делать

- Не перезапускать весь JewAI — сначала проверь один канал.
- Не удалять профиль Chrome — потеряешь логин.
